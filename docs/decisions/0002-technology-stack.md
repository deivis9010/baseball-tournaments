# 0002 — Technology stack

- Status: accepted
- Date: 2026-11-26

## Context

The app must be a simple, responsive web app, used mostly from phones at the field. It is built by one
developer with AI assistance and must run for free during the demo. The developer already knows React,
react-bootstrap, MongoDB and Jest from a previous project.

## Decision

| Piece                | Choice                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Runtime              | Node.js 24 LTS, TypeScript in strict mode                                                                           |
| API                  | NestJS: its uniform structure (modules, controllers, services, DTOs) is easy for agents to follow                   |
| Web                  | React + Vite + react-bootstrap, installable as a PWA                                                                |
| Database             | MongoDB with Mongoose; integrity rules backed by unique indexes                                                     |
| Tests                | Jest in the API, Vitest in the web; same thresholds in both: 70% lines, 70% statements, 69% functions, 60% branches |
| Session              | Short-lived JWT access token (15 min) plus a rotated refresh token in an `httpOnly` cookie, stored hashed           |
| Password reset (MVP) | Temporary link generated by an admin; email delivery later                                                          |
| Hosting (demo)       | Web on Cloudflare Pages, API on Render, database on MongoDB Atlas, all free tiers                                   |
| Repository           | Public on GitHub, so CodeQL and secret scanning are free                                                            |

Exact versions of Nest, React and Vite are checked when each app is created.

## Alternatives considered

- **Express instead of Nest:** already known, but every project ends up with its own structure.
- **PostgreSQL:** fits rosters well, but MongoDB is already known and money is out of scope.
- **Vercel for the web:** the Hobby plan is limited to non-commercial use.
- **Jest in the web:** Vitest reuses the Vite configuration and is faster there.
- **Session only with a long JWT:** cannot be revoked; a refresh token can.

## Consequences

- Render's free tier sleeps after 15 minutes; the first request takes about a minute. Fine for a demo.
- The repository is public: no real data or secrets may ever be committed.
- Web and API must share a domain or a `/api` proxy for the cookie to work.
